# Portfolio
未経験からWebエンジニアを目指して制作したポートフォリオです。

## 制作物

### Todoアプリ
JavaScriptを使用して制作したTodoアプリです。

### 主な機能
- タスクの追加
- タスクの削除
- 完了・未完了の切り替え
- localStorageを使用したデータの保存
- ページ更新後もタスクと完了状態を保持

## 使用技術
- HTML
- CSS
- JavaScript

## 学習・制作について
HTML、CSS、JavaScriptの基礎学習から始め、DOM操作やイベント処理、localStorageを使ったデータ保存を学びながら制作しました。
